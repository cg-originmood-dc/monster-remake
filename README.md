# 噬生・魔物觀測者 — 網頁重製版

Cross Gate（魔力寶貝）的寵物**檔次**計算與推算工具，重製自 2011 年的
Windows 桌面程式「噬生・魔物觀測者」v3.12。

計算核心是 Rust 編成的 WebAssembly，跑在 Web Worker 裡；介面是 Preact。
**沒有後端、沒有伺服器、沒有安裝檔** —— 開網頁就跑，資料都在你自己的瀏覽器裡。

## 能做什麼

- **正算** — 給檔次、等級、加點，算出血魔攻防敏與精神／回復
- **推算** — 給觀測到的能力，反推**掉了幾檔**、**怎麼加的點**、**隨機檔是多少**
- **機率統計** — 候選解不只列出來，還按隨機檔的多項分布加權，告訴你各軸掉檔的機率
- **寵物搜尋** — 「我要一隻 50 級補得到血 400 魔 300 的寵物」，找給你
- **自製寵物** — 圖鑑裡沒有的自己加，或覆寫圖鑑上的資料（存在瀏覽器，可匯出備份）

比起既有的計算機，這個版本的重點在**野寵推算**：野寵沒有手動加點但有入手等級，
解空間跟家寵完全不同。而且原程式在比對檔次時會**針對成長係數表不規則的地方**
放寬取整邊界（`檔次 mod 5 ∈ {0, 1}` 那兩種），所以高等級野寵這種誤差累積大、
整數精確列舉直接無解的情況，它推得出來。細節見 [`CLAUDE.md`](CLAUDE.md) §3.4。

## 開發

```bash
npm install
npm run dev              # 建 wasm + 開 dev server
npm run build            # 打包到 dist/
cargo test --workspace   # 全部測試
```

需要 Rust（含 `wasm32-unknown-unknown` target）、[wasm-pack](https://rustwasm.github.io/wasm-pack/)、Node 20+。

**圖鑑不用轉檔也不進版控** —— 開網頁時直接抓上游那份 CSV，所以上游更新了，
下次重新整理就是新的，不需要重新部署。抓不到就退回編在 wasm 裡的內建表，程式照樣能算。

架構與計算規格見 [`CLAUDE.md`](CLAUDE.md)。

## 原作與素材

這是一個**致敬性質的重製**。原程式與其資料是別人的心血，這裡把出處寫清楚：

|              |                                                                                                                                                                                                                                                    |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **原程式**   | 「噬生・魔物觀測者」v3.12（2011–2023），Borland Delphi 撰寫的 Windows 程式。<br>計算模型、運算模式的分類、側欄的操作流程都是原作者設計的，本專案只是換一套技術重建。                                                                               |
| **介面素材** | `src/assets/ui/` 的 26 張圖（外框、分頁、加減鈕）取自原程式的點陣圖資源。<br>原程式的介面完全是 owner-drawn，這些圖案沒有文字，直接沿用才能保住原本的視覺。<br>**其餘介面（按鈕、欄位、標籤）是照截圖取樣後用 CSS 重畫的，不是原圖。**             |
| **圖鑑資料** | [cg-originmood-dc](https://github.com/cg-originmood-dc/cg-originmood-dc.github.io) 的「專屬寵物」CSV（1069 筆）—— **開網頁時直接抓，不進版控**。<br>**種族名稱也以這份為準。**內建表則來自 cg-pet-calc 的 `PetDefaultData`，兩份揉成一張完整的表。 |
| **計算對照** | [tony1223/cg-pet-calc](https://github.com/tony1223/cg-pet-calc) —— 正算與推算的 baseline。<br>本專案回頭修正了它的 `fullRates` 表（原本只到 index 52 且 51/52 的值有誤）。                                                                         |

原程式的執行檔、反編譯結果與抽資源的腳本**不在這個 repo 裡**。

Cross Gate / 魔力寶貝的相關名詞與數值屬於原遊戲的權利人，本專案與其無關。
